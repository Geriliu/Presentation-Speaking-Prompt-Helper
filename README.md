# English: practice

A speaking practice prompter. Open `index.html` to get started.

Designed to be used during lessons, or to practice on your own. 

The current hardcoded set is **tourism**. 

Change the lesson in the list at the top of `index.html`: `CARDS`, `PHRASES`, `MAP_START`, `MAP_CLOSER`. 

- **Bridge phrases**: joins to keep a point moving
- **Chain drill**: face-down cards; click one to talk in timed (20 sec) conditions
- **Speech map**: start, three points, two bridges, close (90 sec)
